## 🎯 Quick Revision Strategy

### Day Before Exam
1. **Formulas First**: Go through all formulas in Mathematics, CN, OS
2. **Algorithms**: Revise time complexities and key algorithms
3. **TOC**: Review DFA/NFA conversions, Grammar types
4. **OS & DBMS**: Focus on numerical problems
5. **Aptitude**: Practice mental math

### During Exam
- 🕐 Attempt General Aptitude first (usually easier, boosts confidence)
- 📊 Mark questions for review if stuck for > 2 minutes
- ⚠️ Don't leave Numerical Answer Type (NAT) questions blank
- ✅ Double-check negative marking in MCQs
